# SignalDesk Windows Demo

Personal copy for recording the project demonstration.

Download this repository as ZIP while signed into this GitHub account, then extract it. Double-click `SignalDesk.exe` and keep its window open while using the application. Python is included in the executable.

Open http://127.0.0.1:8080 if the browser does not open automatically. Stop the application with Ctrl+C. `Fresh-Demo.bat` starts a new sample database without replacing an earlier run.

All sample accounts use `SignalDesk!2026`. The Employee, Technician and Administrator buttons fill the login details.

The project report is in `report/`. Workflow descriptions are in `docs/WORKFLOWS.md`.

Extract this ZIP to a normal writable folder on a 64-bit Windows laptop.
Double-click SignalDesk.exe. The browser opens at http://127.0.0.1:8080.
If it does not open, enter that address in the browser.
Keep the SignalDesk window open while using the application. Ctrl+C stops it.

Python, Git and an internet connection are not needed to run this package.
The program creates a data folder next to the executable and saves incidents there.
Fresh-Demo.bat starts a new sample database without overwriting earlier runs.
Stop the current server before starting another run.

Sample accounts:
Employee: employee@signaldesk.local
Technician: tech@signaldesk.local
Network technician: network@signaldesk.local
Administrator: admin@signaldesk.local
Password for all sample accounts: SignalDesk!2026

The role buttons fill the sample credentials. Click Sign in to continue.
The first run includes eight sample incidents. A fresh run restores this starting set.
